# Android host

This directory contains the Android Activity, SQLite storage, resources, Gradle configuration, and instrumentation tests.

See the root [README](../README.md), [architecture](../docs/ARCHITECTURE.md), and [development guide](../docs/DEVELOPMENT.md).

The release package is `com.utshab.momentum`. Debug builds use `com.utshab.momentum.qa`. Release signing configuration and build outputs are intentionally excluded from Git.
